Cube escape-room - Defi 1

Jumeau numerique du cube physique. Faites-le rouler pour dechiffrer le code ; le voyant flashe la direction demandee.

Matrice des Sommets

Sommet X Y Z

Commandes

Voyant du cube (code de direction / erreur)

Le premier coup calibre le cube (non compte). Ensuite, suivez le code flashe par le voyant (1 = Haut, 2 = Droite, 3 = Bas, 4 = Gauche) sur 6 coups. La souris deplace seulement la camera, pas le cube.

Etats sauvegardes

Outil de banc : chaque sauvegarde est nommee par la sequence de mouvements qui y mene (H = Haut, B = Bas, G = Gauche, D = Droite). Cliquez le nom pour recharger la pose ; la croix la supprime.
