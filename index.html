Commandes

Cliquez sur les boutons ou utilisez les fleches du clavier. La souris (glisser / molette) deplace seulement la camera, pas le cube.

Etats sauvegardes

Chaque sauvegarde est nommee par la sequence de mouvements qui y mene (H = Haut, B = Bas, G = Gauche, D = Droite). Cliquez le nom pour recharger l'etat ; la croix le supprime.
